# Reporting a Concern

For a suspected confidentiality issue, contact [Matthew Bangle privately on LinkedIn](https://www.linkedin.com/in/matthew-bangle/). Send the affected file path or commit reference and a brief description. Do not post sensitive values, workbooks, or credentials in a public issue.

The supported public entry point is `demo.py`, using synthetic data. Private production connectors are intentionally excluded. Do not add real source exports, browser profiles, credentials, internal identifiers, or backup workbooks to the repository.

Public history was rebuilt from a sanitized baseline on 2026-09-07. Copies made before that rewrite can retain removed material. Re-clone before contributing; do not merge or push old history back into the repository. Removal from GitHub's cached views and unreachable storage requires separate server-side cleanup.
